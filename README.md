# SmartThings Edge Drivers

Community-maintained SmartThings Edge driver projects.

- [Computer Host LAN](computer-host-lan/) — cross-platform Linux and Windows computer monitoring and opt-in power management (release candidate; see the project for current downloads and installation guides).
- [Linux Host LAN](linux-host-lan/) — original Linux-only integration; retained independently for existing users and rollback.

Each project has its own source, driver package key, installation guidance and release history. An Edge driver channel invitation and host agent installation are separate steps. Do not mix protocol v1 Linux Host LAN agents with the protocol v2 Computer Host LAN Edge driver.
