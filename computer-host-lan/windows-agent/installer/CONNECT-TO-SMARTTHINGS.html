Connect Computer Host LAN to SmartThings

The Windows agent runs as a background service on your computer. The separate SmartThings Edge driver runs on your hub. You need both.

1. Install the SmartThings Edge driver

Open the Computer Host LAN driver channel invitation. Sign in with your Samsung account, accept the invitation, enroll your hub if required, then install Computer Host LAN under Available Drivers. If you already installed the driver, you can skip this step.

2. Add your computer in SmartThings

On your phone, open SmartThings and select Add device → Scan nearby. Select the detected Computer Host LAN device. If upgrading, keep your existing SmartThings device; there is no need to remove or re-pair it.

3. Optional power control

If you enabled shutdown, reboot and suspend in the Windows installer, the setup wizard offers a masked authentication key and a Copy authentication key button. In the new SmartThings computer device, open device settings, enable the shutdown/reboot/suspend preference and paste the key into Power control key (64 hex chars).

If you have already closed Setup, an administrator can retrieve the existing key from %ProgramData%\ComputerHostAgent\control-token. Never share this key in forum posts or diagnostics. Reinstalling should not generate a new key for an existing agent.

Local network troubleshooting: The hub and computer must be reachable on a trusted LAN. Automatic discovery uses multicast DNS-SD. If detection fails, the installer also offers manual IPv4 selection, or under Advanced options an explicit local-network firewall fallback. The fallback changes firewall scope; it does not fix blocked multicast or VLAN routing.

Help and feedback

See the project documentation or the SmartThings Community beta thread. The agent remains compatible with the existing ZIP/PowerShell installation.
