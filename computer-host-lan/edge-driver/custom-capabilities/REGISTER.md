# Register custom capabilities

Only maintainers register or update account-owned capabilities. Users
install the existing driver through [SmartThings setup](../../docs/smartthings.md).
Follow [Capabilities and presentations](../../docs/development.md#capabilities-and-presentations)
for namespace verification, registration, additive schema updates,
translations, canonical Git rollback and private-channel qualification.
Do not delete/recreate existing resources or upload a translated CLI read
as a rollback copy. A fork needs its own namespace.
