# Computer Host LAN — licensing / provenance

The current project contains `computer-host-lan/LICENSE` with the **Apache License, Version 2.0** and metadata identifies `Apache-2.0`. This supersedes the older Linux-only draft that said no license file existed.

Before publishing an official GitHub prerelease, the copyright holder should confirm they are authorized to license **all** included original and derived code under Apache-2.0, assess any third-party notices/dependencies, and add applicable attribution/NOTICE files if required. This document does **not** assert that a copyright holder has completed that review.

Dependency inventory: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) records Zeroconf, .NET, Inno Setup and other components. Package generation now copies the notices into both Windows distributions. **This does not substitute for a publisher's final verification of actual restored transitive packages and complete upstream license/copyright notices before a stable release.**

No binary is code-signed. A SHA-256 checksum detects file modification but is not a trusted provenance signature. Label unsigned development binaries honestly.
