# License choice required from the project owner

No open-source license has been selected for this project. Distribution in a public source repository should wait until an explicit choice and a license-file review. Possible options:

- **MIT**: short permissive grant, simple reuse and redistribution terms.
- **Apache-2.0**: permissive with express patent grants and NOTICE handling.
- **GPL-3.0-or-later**: copyleft licensing for derivative distributions.

The decision belongs to the copyright holder. Before publishing, verify provenance of all included code and any third-party contributions, assign copyright/attribution accurately, and make sure contributor licensing matches the chosen terms. Do **not** treat a drafted license choice as permission to republish or relicense upstream work.
