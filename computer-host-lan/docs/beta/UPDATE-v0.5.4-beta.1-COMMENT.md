**Computer Host LAN — Windows installer added to the public beta (v0.5.4-beta.1)**

The next beta includes a proper **Windows 11 x64 graphical installer**. It's now the recommended way to install or upgrade the Windows agent: launch Setup.exe, choose your SmartThings hub (automatically discovered when possible, otherwise enter its IP), decide whether to enable optional power management, and follow the SmartThings connection instructions. If power management is enabled, the wizard offers a separate page where you can display and copy the private key.

**Download (after publication):** [Computer Host LAN v0.5.4-beta.1](https://github.com/ldeora/SmartThingsEdgeDrivers/releases/tag/computer-host-lan-v0.5.4-beta.1). Select `computer-host-lan-v0.5.4-beta.1-windows-x64-unsigned-setup.exe` and compare its SHA-256 against `SHA256SUMS.txt`. The Windows ZIP containing the original PowerShell installation scripts remains available as an alternative, especially for troubleshooting. Both builds are unsigned. Linux users and existing SmartThings driver installations do not need to change anything for this update.

**Existing Windows users can upgrade directly through Setup.exe.** There's no need to remove the device from SmartThings, uninstall the old agent or enter a new key. Setup retains the previous device identity, control key, customized settings and optional power-management setting. The PowerShell fallback also works, but remember to pass `-EnablePower` again on a script-based upgrade if you previously enabled it.

The installer has passed extensive tests on native Windows Server 2025, including its graphical pages, clipboard copying, migrations, upgrades and uninstallation. What we now need from beta testers is actual **Windows 11 + SmartThings hub** feedback: real hub discovery, different display scales, manual IP setup, recovery and WOL. Even a simple report of a successful installation would be useful. Please include Windows build, hub model/firmware and whether you used Ethernet or Wi-Fi, while leaving out IP addresses, MACs, unique IDs and private keys.

Detailed instructions and troubleshooting are in the [installation guide](https://github.com/ldeora/SmartThingsEdgeDrivers/blob/main/computer-host-lan/INSTALLATION.md). Thank you for testing!
