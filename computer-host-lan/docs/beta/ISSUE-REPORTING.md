# Beta feedback and support

Public bug reports should use the [Computer Host LAN issue template](https://github.com/ldeora/SmartThingsEdgeDrivers/issues/new/choose). The owner should confirm this template is present on the default branch before publishing a Community invitation. The SmartThings Community thread can coordinate testers; issues should contain reproducible test IDs and sanitized evidence.

The full report structure and safe-reporting rules are in [FEEDBACK-AND-SUPPORT](FEEDBACK-AND-SUPPORT.md). A release issue isn't a secure way to exchange control keys or other sensitive data.
